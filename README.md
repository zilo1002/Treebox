# 📚 学术引用助手

[![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite&logoColor=white)](https://vitejs.dev/)
[![Vue 3](https://img.shields.io/badge/Vue%203-4FC08D?logo=vue.js&logoColor=white)](https://vuejs.org/)
[![PWA](https://img.shields.io/badge/PWA-5A0FC8?logo=pwa&logoColor=white)](https://web.dev/progressive-web-apps/)

一个基于 Vue 3 + Vite 的移动端学术引用管理工具，支持参考文献自动解析、多种引用格式、题注交叉引用、一键导出 Word 等功能。

---

## ✨ 功能亮点

- **📋 参考文献自动解析**：粘贴 GB/T 7714 格式文献，一键自动提取作者、标题、年份、出版社、页码等信息
- **📐 多种引用位置**：上标 `[1]` / 下标 `[1]` / 括号 `[1]` / 作者-年份 `(张三, 2023)` / 脚注 `①`，导出 Word 保留真正上标/下标格式
- **📖 多格式支持**：GB/T 7714（国标）、APA 7th、MLA 9th、Chicago 17th
- **🔍 智能自动标注**：输入正文中被引用的原文片段，系统自动定位并插入引用标记
- **🏷️ 题注与交叉引用**：独立管理图注/表注，点击即可在正文插入交叉引用（如"见图1"）
- **📄 导出 Word**：文件名自动加 `_已标注`，文档内无多余标题，直接可用
- **🌍 国际化**：内置中文/英文双语切换（vue-i18n）
- **✉️ 信封启动页**：首次进入/关闭标签页重新打开时展示优雅启动动画
- **⬇️ 下拉刷新**：页面顶部下拉即可刷新当前内容
- **📱 PWA 支持**：可添加到手机桌面，离线可用

## 📊 支持格式一览

| 功能 | 说明 |
|------|------|
| 文献导入 | 直接粘贴文本 / 上传 `.docx` `.txt` `.md` |
| 参考文献解析 | 支持 `[M]`专著 `[J]`期刊 `[C]`会议 `[D]`学位 `[EB/OL]`网页 |
| 引用格式 | GB/T 7714 · APA 7th · MLA 9th · Chicago 17th |
| 引用位置 | 上标 · 下标 · 括号 · 作者-年份 · 脚注 |
| 自动标注 | 输入被引用原文，系统自动定位插入 `[n]` |
| 题注管理 | 图注 / 表注，独立编号 |
| 交叉引用 | 点击题注卡片，自动在光标处插入 `（见图1）` |
| 导出格式 | `.docx`（Word），保留上标/下标/页脚页码 |

## 🔒 隐私与安全

- **纯前端运行**：所有文本处理均在浏览器本地完成，不上传任何文件到服务器
- **LocalStorage 仅存储分类数据**：不保存用户文档内容
- **无第三方追踪**：无 Google Analytics、无广告脚本

## 💡 使用提示（踩坑经验）

1. **参考文献粘贴格式**：每行一条，建议保留 `[n]` 序号和 `[M]`/`[J]` 类型标记，解析准确率最高
2. **自动标注找不到内容**：检查粘贴的原文片段是否与正文完全一致（包括标点），系统会先精确匹配，再模糊匹配
3. **上标显示异常**：编辑器中 `<sup>[1]</sup>` 可能显示为普通文本，但导出 Word 后是真正的上标格式
4. **手机端输入框缩放**：iOS 会自动缩放 `< 16px` 的输入框，本工具已统一设为 `16px` 避免此问题
5. **缓存导致新工具不显示**：首次更新后 `DATA_VERSION` 会自动递增并重建缓存，旧分类数据会与新工具自动合并
6. **刷新后回到信封首页**：关闭标签页重新打开会显示信封启动页；同一标签页内刷新保持当前页面
